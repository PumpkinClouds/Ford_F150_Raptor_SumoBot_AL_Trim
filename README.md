# Ford_F150_Raptor_SumoBot_AL_Trim
Sumo Bot Designed by Minh Nguyen, David Hong, Nathan Wignall, and Ana Wise

This Repository contains the code and pcb design for the sumo bot.
The "Ford F150" is a unique 4 wheeled sumo bot

PCB Design Software: KiCad
Microcontroller used: STM32F303CCT6 ([datasheet]([url](https://www.st.com/content/ccc/resource/technical/document/datasheet/f2/1f/e1/41/ef/59/4d/50/DM00058181.pdf/files/DM00058181.pdf/jcr:content/translations/en.DM00058181.pdf)))
Microcontroller Programming Framework: 
3 IR Distance Sensors: Adafruit GP2Y0A21YK0F [Link]([url](https://www.adafruit.com/product/164)) 
4 JSumo ML1 Line Sensors: JSumo JS16249 [Link]([url](https://www.jsumo.com/micro-line-sensor-ml1))

Bot code and pcb for sumo bot competition. (Asgore's fault)
